# Design Specification: NeuroDiOS Roller Coaster Framework

**Document ID:** NEURODIOS-RCF-DS-001  
**Version:** 1.0.0  
**Date:** 2026-05-29

---

## 1. Architectural Position

The Roller Coaster Framework sits above the raw Behavioral Health Primitives and below the higher Morphogenetic and Task Management layers. It is the first major **active generative** subsystem in NeuroDiOS — it does not only react to unhealthy states; it intentionally creates productive psychological motion.

It consumes the primitives catalogue (including the new clustering and relational mode analysis) as its fundamental material.

---

## 2. Key Design Concepts

### 2.1 Clusters as Track Sections
- Load & Depletion Cluster → Long, grinding ascents (high inertia)
- Masking & Emotional Volatility Cluster → Sharp twists, drops, and inversions (high surface tension)

### 2.2 Relational Modes as Track Geometry
The relationships between primitives determine how "connected" or "jarring" the transitions feel:
- Mirror relationships create smooth, reinforcing curves.
- Counter relationships create opposing forces (useful for controlled tension).
- Synth relationships create emergent "loops" or new track elements.
- Observer relationships act as sensors along the track.

### 2.3 Anchoring by Emulation
One primitive can be temporarily "emulated" at low intensity to act as psychological ballast during dangerous transitions. This is a deliberate design feature, not a bug.

### 2.4 Uplift as an Emergent Property of Contrast
Insight is not generated by the stress phase or the relief phase alone. It emerges in the *mechanism between* them — the differential, the narrative completion, the state memory, and the protected coast period.

---

## 3. Cycle Structure (Design)

The canonical Roller Coaster cycle consists of six phases with explicit entry/exit conditions and mechanisms.

The framework must support both:
- System-proposed cycles (based on current primitive readings + user history)
- User-initiated or co-designed cycles (with appropriate guardrails)

---

## 4. Data Structures

- **PrimitiveCluster**
- **RelationalModeGraph** (edges between primitives/clusters typed by the defined modes)
- **RollerCoasterCycle** (sequence + parameters + log)
- **UpliftEvent** (timestamped insight with linkage back to specific cycle segment and mechanisms)
