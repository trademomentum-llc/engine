## 1. Core Concept

The Roller Coaster Framework treats behavioral health states not as problems to be avoided at all costs, but as **track segments** that can be deliberately traversed in controlled cycles.

**The Uplift Principle:**
Stress (ascent) → Peak tension → Relief/Coasting (descent) → Insight crystallization

By intentionally (but safely) moving the user through sequences of high-load primitives followed by relief phases, the system generates the conditions for genuine insight, creativity, and psychological integration — while using the adaptation offsets from the primitives to prevent damage.

This is the "very beginning" operationalization of uplift: the system does not merely stabilize; it actively engineers productive psychological motion.

## 2. Extended & Clustered Primitives

The original six primitives are retained but now organized into **two primary clusters** and analyzed through explicit relational modes.

### Cluster A: Load & Depletion Cluster (The Ascent Rails)
- BH-01: Executive Depletion
- BH-03: Sensory Overload
- BH-04: Context Switching Fragmentation
- BH-06: Sleep Debt / Circadian Misalignment

**Cluster Character:** Cumulative cost. High inertia. Slow to build, dangerous when sustained.

### Cluster B: Masking & Emotional Volatility Cluster (The Twists & Drops)
- BH-02: Masking Load Accumulation
- BH-05: RSD / Emotional Dysregulation Spike

**Cluster Character:** High surface tension. Rapid state changes. Can produce sudden drops or explosive releases.

## 3. Relational Modes Between Primitives

Every pair of primitives (or clusters) can be related through these modes:

### Primary Modes
- **Mirror**: Two primitives amplify the same underlying dynamic (e.g., Executive Depletion mirrors Context Switching Fragmentation in their effect on working memory).
- **Counter**: One primitive opposes or compensates for the other (e.g., Sensory Overload can be partially countered by controlled Masking in short bursts for some individuals).
- **Orthogonal**: Independent axes with minimal direct interaction (e.g., pure Sleep Debt vs. acute RSD spike).
- **Synth (Synthesis)**: The combination produces an emergent state greater than the sum (e.g., Masking + Sensory Overload → "Autistic Burnout" state with unique properties).
- **Observer**: One primitive acts as a reliable early warning or measurement lens for another (e.g., Context Switching Fragmentation as an observer of rising Executive Depletion).

### Compound Modes (as requested)
- Mirror-Counter
- Mirror-Anchored
- Orthogonal (pure)
- Counter-Synth
- Observer-Mirror
- etc.

The system must be able to compute and expose the current dominant relational mode between active primitives.

## 4. Anchoring by Emulation of a Prime

**Definition:** The system can designate one primitive as an **Anchor Prime** and deliberately emulate a controlled, bounded version of it to stabilize the user during transitions or high-volatility periods.

Example:
- User is in heavy Masking Load + RSD risk.
- System chooses **Executive Depletion** as Anchor Prime.
- It emulates a mild, safe version of depletion (e.g., gently enforcing a slightly reduced context budget and suggesting one low-stakes task) to create a "known quantity" sensation of manageable tiredness, which reduces the terror of the emotional volatility.

This creates psychological grounding: "I know this feeling. I have tools for this."

Anchoring is always temporary and explicitly bounded.

## 5. The Roller Coaster Track Model

### Phases of a Cycle

1. **Loading / Baseline** (Coast)
   - Low intensity across clusters.
   - System performs light observation.

2. **Ascent (Stress Induction)**
   - System allows or gently encourages controlled entry into one or more Load Cluster primitives.
   - Tension is deliberately built (task complexity, sensory input, social demand, time pressure — all within safe parameters defined by the user's current adaptation offsets).

3. **Peak / Apex**
   - Maximum productive tension.
   - System monitors closely for crossing into unhealthy fluctuation territory.

4. **Descent (Relief / Release)**
   - Rapid, supported transition into relief primitives or states.
   - Mechanisms: context lock, sensory reduction, agency-rebuilding micro-tasks, social decompression, etc.

5. **Coast / Crystallization**
   - Low-demand period where the system actively protects space for insight emergence.
   - This is where "uplift" (new connections, reframing, creative output) is most likely to occur.

6. **Integration / Reset**
   - System helps the user metabolize any insights.
   - Returns to a new, slightly higher baseline (or repairs damage if the cycle was too intense).

### Uplift Generation Mechanisms (the "mechanisms in between")

- **Tension Differential**: The contrast between ascent and descent creates psychological space for new pattern recognition.
- **Narrative Completion**: The system can help the user construct a coherent story of the cycle ("I went through X, came out with Y").
- **State Memory**: Capturing the exact sequence of primitives traversed and the transitions between them.
- **Insight Tagging**: During coast phases, the system surfaces relevant past states or external knowledge at the moment of relief.

---

## 6. Capturing Primitives and Mechanisms In Between

The framework requires a **Cycle Log** that records:

- Sequence of primitives activated (with timestamps and intensity curves)
- Dominant relational modes active during each segment
- Which prime was used as Anchor (if any)
- Transition mechanisms employed
- Measured uplift indicators (subjective insight reports + objective markers such as novel task approaches, reduced future masking load, etc.)

This log becomes a first-class data structure in NeuroDiOS shared state.

---

## 7. Safety & Determinism Constraints

- Every ascent must have pre-declared exit conditions and relief mechanisms.
- No cycle may proceed if any primitive is already in a CRITICAL unhealthy fluctuation state.
- The system always maintains the ability to "brake" into full relief mode.
- All cycles are logged and reviewable (human + MorphogeneticMaintainer).

---

**This framework turns the primitives from purely defensive monitoring tools into active instruments for psychological development and insight generation.**

The Roller Coaster is not about making life constantly comfortable. It is about making the uncomfortable periods *productive* and the relief periods *generative*.
